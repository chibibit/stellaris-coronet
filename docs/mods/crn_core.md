# crn_core — Coronet: Core

The shared framework of the family. Every other Coronet mod lists it in `dependencies`, so it always loads first
and other mods can rely on what it defines.

## What it changes in the game

Today, nothing a player notices. On game start it:

- sets the global flag `crn_core_active`, which other Coronet mods and compatibility patches test with
  `has_global_flag = crn_core_active`;
- writes `Coronet: Core loaded` to `game.log`, the proof that the mod loaded and its on_action fired.

## Files

| File | What |
|---|---|
| `descriptor.mod` | Name, version, supported game version, tags, thumbnail. No dependencies: this is the root. |
| `common/on_actions/crn_core_on_actions.txt` | Adds `crn_core.1` to `on_game_start`. On_action lists merge, so vanilla's list is untouched. |
| `events/crn_core_events.txt` | Namespace `crn_core`. Event `crn_core.1`: hidden, triggered only, sets the flag and logs. |
| `localisation/english/crn_core_l_english.yml` | The mod's name and description keys. The nine other language folders hold copies generated by `scripts/loc-sync.sh`. |
| `thumbnail.png` | 512x512 launcher and Workshop tile, rendered by `scripts/brand.sh` from `brand/mods/crn_core.conf` (emblem `star`, the family's own heart; accent Signal teal). Never edited by hand. |

## Vanilla files overridden

None.

## What other mods may rely on

- `crn_core_active` global flag, set before any country event of game start runs.
- Later: scripted triggers and effects under `common/scripted_triggers/` and `common/scripted_effects/`, icons
  under `gfx/interface/icons/`. Anything shared by two Coronet mods moves here rather than being duplicated.
